# Dataset Selection

## Selected Dataset

**Name**

bitext/Bitext-customer-support-llm-chatbot-training-dataset

---

## Why It Was Selected

- Large dataset (~26.9k examples)
- Well-defined customer support categories
- Includes customer intent labels
- High-quality and consistent examples
- Suitable for transformation into TicketMindAI's schema

---

## Fields Available

- instruction
- category
- intent
- response

---

## Fields We Will Generate

- priority
- sentiment
- summary

---

## Decision

The Bitext dataset will serve as the primary raw dataset for TicketMindAI.
